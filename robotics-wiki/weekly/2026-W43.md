# 2026-W43 로봇 지식 초기 조사

- 조사일: 2026-10-21
- 범위: 사용자가 지정한 두 교육과정 + 공식 ROS 2/제어·시뮬레이션·비전 자료 + Hugging Face LeRobot

## 이번 조사에서 확인한 내용

- KANT 커리큘럼은 Python/ROS 2/좌표계/OpenCV 기초를 시작으로 비전 추적, 자율주행·AI, 다중 로봇·공정, Digital Twin/Sim-to-Real까지 장기 순서를 제시한다.
- PinkLAB 실습은 Ubuntu 24.04/ROS 2 Jazzy 예제 환경에서 MuJoCo, ROS 2, SLAM/Nav2, MoveIt 2, ArUco, LLM 계획을 연결하는 2일 미션을 제공한다. 이것은 하나의 과정 사례로 기록하고 회사 표준 버전과 동일시하지 않는다.
- 시뮬레이터는 하나로 통일할 대상이라기보다 작업에 따라 고른다: ROS 패키지 통합은 Gazebo, 빠른 physics/control 학습은 MuJoCo, GPU 합성 데이터/대규모 가상환경은 Isaac Sim/Lab을 평가 후보로 둔다.
- Hugging Face LeRobot은 데이터 수집·저장·정책 학습·평가·배포를 함께 다루므로 로봇 학습 범주에 포함했다. 개별 모델/데이터 사용 전 card와 license를 검토한다.
- ROS 배포판, 시뮬레이터, MoveIt/Nav2/ros2_control 간 호환성은 실제 설치 시 공식 지원 행렬로 다시 확인한다.
