# 2026-W43 로봇 지식 초기 조사

- 조사일: 2026-10-21
- 범위: 사용자가 지정한 두 교육과정 + 공식 ROS 2/제어·시뮬레이션·비전 자료 + Hugging Face LeRobot

## 이번 조사에서 확인한 내용

- KANT 커리큘럼은 Python/ROS 2/좌표계/OpenCV 기초를 시작으로 비전 추적, 자율주행·AI, 다중 로봇·공정, Digital Twin/Sim-to-Real까지 장기 순서를 제시한다.
- PinkLAB 실습은 Ubuntu 24.04/ROS 2 Jazzy 예제 환경에서 MuJoCo, ROS 2, SLAM/Nav2, MoveIt 2, ArUco, LLM 계획을 연결하는 2일 미션을 제공한다. 이것은 하나의 과정 사례로 기록하고 회사 표준 버전과 동일시하지 않는다.
- 시뮬레이터는 하나로 통일할 대상이라기보다 작업에 따라 고른다: ROS 패키지 통합은 Gazebo, 빠른 physics/control 학습은 MuJoCo, GPU 합성 데이터/대규모 가상환경은 Isaac Sim/Lab을 평가 후보로 둔다.
- Hugging Face LeRobot은 데이터 수집·저장·정책 학습·평가·배포를 함께 다루므로 로봇 학습 범주에 포함했다. 개별 모델/데이터 사용 전 card와 license를 검토한다.
- ROS 배포판, 시뮬레이터, MoveIt/Nav2/ros2_control 간 호환성은 실제 설치 시 공식 지원 행렬로 다시 확인한다.

## 지식 구조 보강 (2026-10-21)

- 기존 다섯 범주에서 직접 다루지 않던 검증·안전·보안 자료를 `validation-safety-security.md`로 추가했다. 단위/launch test → 시뮬레이션 → HIL → 통제된 실기 순서와 증거 구분, 위험 평가, ROS 2 DDS 보안 기본 확인점을 포함한다.
- ros2_control 실제 장치 연동에서 빠지기 쉬운 hardware lifecycle, 비동기 I/O, 제어 주기/jitter를 ROS 2 제어 범주에 명시했다. 비동기 API/동작은 Kilted 공식 문서에서 확인했으며, 다른 배포판에 그대로 적용하지 않는다.
- 산업용 로봇 안전 표준은 로봇 자체와 응용 통합 범위를 구분해 확인해야 하므로 ISO 카탈로그를 출처 목록에 추가했다. 표준 전문은 복제하지 않으며 적용성은 작업·관할별로 검토하도록 명시했다.
- launch_testing, ROS 2 Security Enclaves, OSHA Robotics 자료를 출처 등록부에 추가했다. OSHA 자료는 미국 작업장 참고로만 취급한다.

## 추가 추적 후보

- 데이터셋 사전의 기준을 강화했다. 공식 제작자 자료로 로봇 구성·형식·이용 조건을 대조한 BridgeData V2, RoboAug, ALOHA-Cosmos-Policy, RoboTwin을 핵심 목록으로 두고, RH20T는 하위 라이선스/개인정보/용량 조건이 확인되는 경우만 쓰도록 표시했다. DROID는 7축 전이 자료로 분리했다. 데이터 라이선스가 확인되지 않거나 pose annotation 중심인 후보는 핵심 추천에서 제외했다.
- 사용자 확인으로 사내 로봇을 FAIRINO FR3로 식별했다. 공식 제품 페이지의 기본 사양(6축·622mm·±0.02mm·정격 payload 3kg)과 매뉴얼의 payload 설정 범위(3kg)를 기록했으며, 제품 페이지의 max 5kg 문구와 차이가 있어 load curve/제조사 확인 전 허용하중으로 쓰지 않도록 표시했다. 정확한 suffix와 controller revision은 미확인이다.

- ROS 2 Lyrical/Kilted/Jazzy와 Ubuntu 지원 상태 변화
- MuJoCo–ROS 2 bridge 유지보수와 ros2_control 연동
- OpenCV 5와 4.x 병행 지원 및 migration 조건
- LeRobot 데이터 형식, 정책, 지원 하드웨어·시뮬레이터 변화
- CAD→URDF/MJCF/USD 변환과 디지털 트윈 자산 검증 흐름

# 2026-W43 제조사별 매뉴얼 확장

- 확인일: 2026-10-21
- 국내 제조사 중 두산로보틱스, 레인보우로보틱스, 뉴로메카, 한화로보틱스, HD현대로보틱스의 공식 문서 경로와 대표 기종을 추가했다. 교육용 매니퓰레이터 기준으로 ROBOTIS OpenMANIPULATOR-X도 별도 분류했다.
- 대표 문서 상태: Rainbow RB 시리즈 한국어 사용자 매뉴얼 V6.3(표기상 2024-09 업데이트); Hanwha HCR 2세대/3세대 사용 설명서; Doosan A와 M/H 매뉴얼; HD Hyundai HRBook 및 Hi5a/Hi6/Hi7 매뉴얼 분류.
- 뉴로메카 공식 공개 제품 다운로드에서는 카탈로그/3D CAD를 확인했고, 사용자 매뉴얼 공개 링크는 확인하지 못했다. 대신 공개 `indy-ros2` Jazzy branch의 지원 모델/시뮬레이터 경로를 기록했으며 공급사 매뉴얼을 대체하지 않는다.
- 제조사별 설치 지침, 모델/세대/컨트롤러 구분, 공개 문서의 한계를 [매뉴얼 인덱스](../manufacturers/README.md) 및 각 브랜드 페이지에 반영했다.
- 이 작업은 공개 문서 진입점 조사다. 회사 실장비 재고, 납품 개정판, 펌웨어·컨트롤러 호환성을 알 수 없으므로 실제 운전 전 장비 명판 및 공급사 문서로 다시 맞춘다.
