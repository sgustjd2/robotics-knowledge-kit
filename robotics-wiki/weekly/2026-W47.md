# 2026-W47 로봇 개발 지식 갱신

- 조사일: 2026-11-16 (KST)
- 비교 기준: [2026-W46](2026-W46.md), 최근 확인일 2026-11-09
- 공식 upstream 릴리스·PR과 dataset card를 우선 확인했다. 열린 PR이나 성능 측정 사례는 일반적인 보장으로 간주하지 않는다.

## 이번 주 변경

### 로봇 학습·시뮬레이션 데이터

- NVIDIA [PhysicalAI Robotics Locomanipulation GRAIL dataset card](https://huggingface.co/datasets/nvidia/PhysicalAI-Robotics-Locomanipulation-GRAIL)는 2026-11-10 `stair_p3`/`stair_p4`에 계단 오르내림 12,512 motion과 procedurally generated stair asset 2,000개를 추가했다고 기록한다. Unitree G1에 retarget한 physics-validated trajectory를 Isaac Lab 시뮬레이션에서 실현한 데이터다. 카드 라이선스는 CC BY-NC 4.0이므로 비상업 연구 검토에만 분류하고 회사의 상업 목적 학습·배포에는 사용하지 않는다. 6축 팔 데이터가 아니므로 [6축 사전](../datasets/6dof-arm-dataset-dictionary.md)에는 추가하지 않는다. Dataset viewer가 현재 표시되지 않아 파일/trajectory 수치와 개별 asset 조건은 카드·원본 파일을 사용 전에 더 확인해야 한다.

### ROS 2 제어

- [ros2_control #3754](https://github.com/ros-controls/ros2_control/pull/3754)가 2026-11-10 master에 병합됐고 Jazzy [#3773](https://github.com/ros-controls/ros2_control/pull/3773), Kilted [#3774](https://github.com/ros-controls/ros2_control/pull/3774) backport도 병합됐다. controller update cycle마다 clock/time 관련 참조와 zero-time 값을 여러 차례 만들던 것을 cycle당 한 번으로 줄인다. PR 본문은 mock hardware와 no-op controller 기준 10·30 controller 구성에서 controller-manager update 오버헤드가 각각 약 20%·25% 줄었다고 보고하지만, 단 2회 median 비교로 전 시스템 성능 향상을 보장하지 않는다.
- [ros2_control #3772](https://github.com/ros-controls/ros2_control/pull/3772)는 11-10 Rolling/master에 병합됐다. Rolling 이후 제거되는 `libstatistics_collector` 의존성을 `hardware_interface`/`controller_manager`에서 제거하고 자체 `StatisticData` 타입을 둔다. downstream build나 package manifest가 이 라이브러리를 직접 의존하는 경우에만 migration 영향이 있는지 확인한다.
- W46의 clock-reset 처리 [#3745](https://github.com/ros-controls/ros2_control/pull/3745)와 shutdown race 수정 [#3721](https://github.com/ros-controls/ros2_control/pull/3721)은 11-16 확인 시 여전히 open이다. #3745는 PR 단계에서 backward jump 때 loop sleep을 상대 시간으로 바꾸고 controller에 전달되는 음수 period를 nominal period로 clamp하며, reset 후 stateful controller 재활성화를 문서화한다. 아직 released behavior가 아니므로 simulator 통합별 검증을 유지한다.

## 이번 주 새 정식 릴리스 변경을 확인하지 못한 분야

- OpenCV: upstream release 목록의 최신은 5.1.0(11-06), ROS 2/nav/manipulation: Nav2 1.5.3 및 Jazzy 1.3.14(10-17) 이후 구간 내 새 릴리스를 확인하지 못했다. MoveIt 2도 새 공식 release를 확인하지 못했다.
- LeRobot: upstream release 목록에서 v0.7.0(11-05)이 여전히 최신으로 표시된다. MuJoCo: 4.0.0(11-06) 이후 새 numbered release를 확인하지 못했다.
- Isaac Lab/Isaac Sim, Gazebo, Blender/CAD: 이번 비교 구간에 새 공식 정식 릴리스를 확인하지 못했다. Isaac Lab 3.0 GA와 앞서 기록한 Isaac Sim 6.2 조합이 기준이다.
- Hugging Face robotics 검색 및 논문 원문: GRAIL의 새 simulation motion subset 외에 출처·embodiment·license가 확인된 새 6축 실기 dataset 또는 정책을 추가하지 않았다.

## 남은 확인

- CC BY-NC 4.0인 GRAIL 데이터의 비상업 범위를 넘어 이용할 수 있는 권한은 확인되지 않음. 회사 업무에는 사용 금지로 취급.
- ros2_control #3754/#3772가 대상 binary package에 반영되는 버전과 downstream 의존성을 distro별로 확인.
- #3721 shutdown race와 #3745 backward clock jump 수정의 merge/release 상태를 다음 주 다시 확인.
