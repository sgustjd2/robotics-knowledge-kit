## 이번 주 변경

### 비전·센서

- [OpenCV 5.1.0](https://github.com/opencv/opencv/releases/tag/5.1.0)은 2026-11-06 공개된 5.x 첫 기능 업데이트이며 코드 라이선스는 Apache-2.0이다. [공식 changelog](https://github.com/opencv/opencv/wiki/OpenCV-Change-Logs)는 객체 추적의 detection-to-track matching에도 쓸 수 있는 `cv::linearAssignment()`와 FP8/core 개선을 기록한다. DNN classic engine 및 `readNetFromTensorflow()` 제거, engine enum 교체가 포함되므로 기존 TensorFlow 모델을 ONNX로 전환하고 런타임·카메라 보정·추적 회귀를 통과시킨 뒤 적용한다.

### robot learning·Hugging Face

- [LeRobot v0.7.0](https://github.com/huggingface/lerobot/releases/tag/v0.7.0)은 2026-11-05 공개됐다. Hub/저장소 데이터 스트리밍, 원격 policy inference와 학습·하드웨어 경로 변경이 들어갔지만 v0.6.1에서 호환성 파괴 변경이 많다. Linux PyPI의 기본 PyTorch/Torchvision은 CUDA 13 빌드(NVIDIA driver 580.65 이상), `cu128` index 제거, FSDP1→FSDP2/HSDP, W&B→Trackio, checkpoint/API 변화가 주요 migration 항목이다. 코드 라이선스는 Apache-2.0(저장소 LICENSE 및 third-party notices 확인); 개별 데이터·모델은 각 Hub card 라이선스를 따로 검토한다. [릴리스 글](https://huggingface.co/blog/lerobot/lerobot-release-v070)은 상세 기능 설명으로만 참고한다. FR3 지원이나 안전한 실기 구동을 의미하지 않으므로 해당 로봇 드라이버와 명령 경계를 별도 검증한다.

### ROS 2 제어·시뮬레이션 경계

- W45에서 open으로 기록한 ros2_control #3718 nested namespace YAML 문제는 수정 [#3719](https://github.com/ros-controls/ros2_control/pull/3719)이 11-02 master에 병합됐고 [Jazzy #3746](https://github.com/ros-controls/ros2_control/pull/3746), [Kilted #3747](https://github.com/ros-controls/ros2_control/pull/3747) backport도 병합됐다. 저장소 merge만으로 설치된 binary에 반영됐다고 단정하지 말고, 패키지 버전 확인 후 실제 nested YAML로 `load_controller`를 검증한다.
- shutdown race 이슈 #3716의 대응 [PR #3721](https://github.com/ros-controls/ros2_control/pull/3721)은 11-09 확인 시 open이다. simulator reset/backward clock jump 관련 [PR #3745](https://github.com/ros-controls/ros2_control/pull/3745)도 open이며, 통합 때 controller/trajectory 상태를 reset 후 어떻게 재초기화할지 프로젝트가 정해야 한다. 두 PR 모두 released behavior로 취급하지 않는다.

### 시뮬레이션·디지털 트윈

- [MuJoCo 4.0.0](https://github.com/google-deepmind/mujoco/releases/tag/4.0.0)은 2026-11-06 정식 공개됐으며, 11-07 [upstream 발표](https://github.com/google-deepmind/mujoco/discussions/3773)가 변경 사항을 설명한다. Studio/Filament 기반 viewer·SDK, 개선된 deformables와 speculative contacts를 소개하고 Python 배포를 `mujoco-core`와 선택 컴포넌트로 분리했다. Apache-2.0 코드와 별도 문서/자산 라이선스를 구분한다. 3.x에서 올릴 때 패키지 uninstall 후 재설치를 안내하며 Python 3.10 지원 중단, soft-body API 변경이 있으므로 기존 MJCF·plugin·MuJoCo ROS bridge의 호환성 시험 후 채택한다. 4.0 release note와 GitHub discussion은 기능 소개의 upstream 근거이지 FR3 실물 또는 sim-to-real 성능 검증은 아니다.
