# 2026-W44 로봇 개발 지식 갱신

- 조사일: 2026-10-26 (KST)
- 비교 기준: [2026-W43](2026-W43.md), 최근 기록일 2026-10-21
- 추가한 자료는 지난 점검 뒤 새로 게시되었거나, 새로 열린 upstream 설계 논의뿐이다. 저자 발표·공개 이슈·제품 동작을 공식 보장/표준으로 격상하지 않았다.

## 이번 주 반영

### 시뮬레이션·디지털 트윈·자산

- NVIDIA가 2026-10-21 [SimReady Central 소개](https://huggingface.co/blog/nvidia/simready-central-assets-robotics-ai-factories)를 게시했다. OpenUSD 기반의 로봇/그리퍼/공장 설비 자산을 프로파일별 물리·충돌·관절·semantic 요구와 검증 근거를 통해 찾는 라이브러리로 소개한다. [HF 라이브러리 저장소](https://huggingface.co/datasets/nvidia/simready-central-library)는 Alpha이며 파일 열람 전에 계정 정보 제공 동의를 요구한다. 게시물의 무료/ungated 설명을 파일 접근 허가나 전체 라이브러리의 공통 license로 해석하지 않도록 [디지털 트윈 문서](../categories/simulation-digital-twin.md)에 조건을 기록했다.
- 2026-10-23 공개된 [Mundo](https://mundo-world-model.github.io/) 연구 프리뷰는 촬영 이미지로 만든 3D proxy/scene program에서 MuJoCo로 상태·접촉을 계산하고 video model로 외관을 합성하는 real-to-sim 접근을 제시한다. [프로젝트 저장소](https://github.com/Luo-Yihang/Mundo)는 코드와 weights가 11월 말 예정이라고 표시하며, 발표 자료는 느린 생성, 작은 물체 상호작용 환각, 장기 일관성 한계를 공개한다. 재현 도구나 실기 transfer 검증으로 보지 않고 개념 연구로 등록했다.

### ROS 2 제어·시뮬레이션 경계

- ros2_control에 2026-10-22 열린 [simulator reset 설계 논의 #3715](https://github.com/ros-controls/ros2_control/issues/3715)를 추적 대상으로 추가했다. time rewind 뒤의 제어 루프 정체뿐 아니라 controller 적분/trajectory 상태와 simulator의 관절 상태를 같이 복구할 책임을 논의한다. 열린 이슈이며 확정 API가 아니므로, 기존 설계 지침에는 simulator integration의 reset/restore semantics를 시험하고 미지원이면 재초기화 절차를 두도록만 반영했다.

### Robot learning·Sim-to-Real

- [Microduck + Isaac Lab 3.0 예제](https://huggingface.co/blog/nvidia/microduck-isaac-lab-sim-to-real)는 biped 보행 정책을 병렬 시뮬레이션에서 학습하고 평가한 뒤 ONNX로 내보내 실물 Microduck에 적용하는 경로를 소개한다(게시일 2026-10-21). 이는 보행용 별도 기종의 사례라 6축 팔/FR3에 대한 호환 또는 안전 근거로 분류하지 않았다.
- [LeRobot release 이력](https://github.com/huggingface/lerobot/releases)에서 v0.4.0은 GitHub 화면상 2026-10-23 게시로 보이지만 연결된 [release blog](https://huggingface.co/blog/lerobot-release-v040)는 2025-10-24 게시로 표시한다. 0.6.x 릴리스보다 낮은 버전의 날짜/순서도 모순되므로 이번 주 신규 기본 버전으로 반영하지 않았다. tag와 release provenance를 다음 점검에서 재확인한다.

## 확인했으나 이번 주 추가 변경 없음

- ROS 2/ros2_control 공식 릴리스·문서, MoveIt 2와 Nav2 upstream release 페이지: 이번 비교 구간에 채택할 새 릴리스/호환 행렬은 확인되지 않았다. 단, 위 reset 이슈는 별도 관찰.
- OpenCV upstream release 페이지와 2026 기술위원회 기록: 최신 확인 가능한 회의록은 2026-10-21로 이번 점검 사이 후속 변경을 확인하지 못했다. OpenCV 5.1은 회의록상 지연/개발 중 정보가 있어 released 버전으로 간주하지 않는다.
- MuJoCo upstream releases: 3.15.0의 2026-10-05 릴리스는 지난 점검 전 발표되어 이번 주 변경으로 중복 기록하지 않았다. Isaac Sim 6.2 문서는 조사했으며 이번 점검 구간에 새 버전 번호를 확정할 근거를 찾지 못했다.
- 6축 실기 궤적 데이터셋: 이번 주 공식 제작자 자료에서 기존 사전에 추가할 만한 새로운 6축 실기 trajectory dataset을 검증하지 못했다. SimReady Central은 시뮬레이션 자산 색인이지 trajectory dataset이 아니므로 데이터셋 사전에 섞지 않았다.
- 공통 카테고리의 durable 지침과 출처 상세: [시뮬레이션·디지털 트윈](../categories/simulation-digital-twin.md), [로봇 학습·LLM](../categories/robot-learning-llm.md), [출처 등록부](../sources/registry.md).

## 남은 확인

- SimReady Central의 Alpha 접근 약관, 포함 자산별 revision·license·SimReady profile을 사용 전 재검토.
- Mundo 코드/weights가 예정일에 실제로 공개되는지, 공개되면 license·설치 조건·재현 평가를 확인.
- ros2_control #3715 논의가 API, contract 또는 문서 변경으로 결론나는지 추적.
- LeRobot v0.4.0 release 화면의 날짜/version 순서가 tag 이동·재발행인지 확인하기 전 프로젝트 기본 버전은 변경하지 않음.

## 누락 정정 (2026-11-02)

- 이번 재점검에서 2026-10-22의 [MuJoCo 3.17.0](https://github.com/google-deepmind/mujoco/releases/tag/3.17.0)과 10-14의 3.16.0을 확인했다. W44 작성 때 3.15.0을 최신으로 잘못 남겼다. W45에 최신 기능과 마이그레이션 주의점을 정정했다.
- 2026-10-20 Isaac Lab 3.0.0 GA 릴리스와 10-22 GA 공지도 W44 검토에서 누락했다. 이는 Isaac Sim 6.2와 별도 제품 버전이며, W45에 backend/호환성 및 breaking changes를 기록했다.
