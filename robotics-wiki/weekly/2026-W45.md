# 2026-W45 로봇 개발 지식 갱신

- 조사일: 2026-11-02 (KST)
- 비교 기준: [2026-W44](2026-W44.md), 최근 확인일 2026-10-26
- 공개 upstream에서 확인한 열린 이슈는 보고/추적 상태로 기록하며 해결된 동작이나 릴리스 보장으로 취급하지 않는다.

## 이번 주 반영 및 정정

### 시뮬레이션·디지털 트윈

- [MuJoCo 3.17.0](https://github.com/google-deepmind/mujoco/releases/tag/3.17.0)은 2026-10-22 공개된 upstream 최신 릴리스로 확인했다. W44에서 3.15.0을 최신으로 남긴 기록을 정정한다. 3.17은 thread pool 기반 batch API(`mujoco.batch`)로 같은 모델의 여러 독립 시뮬레이션을 실행하며, release note는 일반 loop와 bit-identical 결과를 보고한다. 3.16.0(2026-10-14)은 frame scale 기능과 일부 C API 변경을 포함한다. 기존 flex/actuator 모델 결과 및 custom decoder/resource-provider 코드는 버전 고정 환경에서 regression 검증한다. 소스 코드 Apache-2.0; 문서·이미지는 별도 CC BY 4.0.
- [Isaac Lab 3.0.0](https://github.com/isaac-sim/IsaacLab/releases/tag/v3.0.0)은 10-20 공개됐고 10-22 GA 공지가 게시됐다. 이는 Isaac Sim 버전과 구분되는 Isaac Lab major release이며, MuJoCo-Warp를 포함한 Newton, OVPhysX/OVRTX, Isaac Sim backend의 다중 경로와 kit-less 실행을 소개한다. 릴리스에 적힌 조합 기준은 Isaac Sim 6.2, Python 3.12, PyTorch 2.11/CUDA 13, Warp 1.17, Newton 1.6.1, RSL-RL 5.5.1. quaternion WXYZ→XYZW, `.data.*`의 `ProxyArray`, index/mask write API 분리는 호환성 파괴 변경이므로 새 환경에서 migration 검증 후 채택한다. framework license는 BSD-3-Clause; dependency·asset 및 Isaac Sim 별도 조건 확인. W44의 Isaac Lab 누락을 이번 주에 발견해 여기와 [시뮬레이션 문서](../categories/simulation-digital-twin.md)에 보완했다.

### ROS 2 제어

- [ros2_control #3716](https://github.com/ros-controls/ros2_control/issues/3716)은 10-27 열린 upstream bug 보고다. 종료 시 실시간 loop의 `update()`와 controller `release_interfaces()`가 겹칠 수 있다는 재현이 보고됐고, 제보 환경은 Ubuntu 24.04/Jazzy controller_manager 4.45.2 및 master다. 미해결 이슈이므로 모든 배포판에서 발생한다고 일반화하지 않는다. 프로젝트는 mock hardware에서 controller 활성화 후 종료를 반복하는 회귀 시험을 추가하고, 이슈/수정 릴리스를 추적한다.
- [ros2_control #3718](https://github.com/ros-controls/ros2_control/issues/3718)은 10-28 열린 upstream bug 보고다. 특정 nested namespace 형식의 유효한 YAML parameter 파일이 `ros2 control load_controller`에서 누락된다는 재현이 있다. 아직 해결/적용 버전 근거가 없으므로 현재 launch 설정의 YAML 구조를 시험하고, 이슈 상태와 대상 배포판 패키지 버전을 확인한다.

## 확인했으나 지난 점검 이후 릴리스 변경 없음

- ROS 2/ros2_control, Nav2, MoveIt 2 upstream 릴리스/변경 이력: 이 구간에 신규 채택 릴리스를 확인하지 못했다. Nav2의 1.5.3(10-17)과 MoveIt의 2.15.2(9-16)는 비교 기준일 이전이다. ros2_control에는 위에 적은 새 이슈가 있으나 이슈는 release가 아니다.
- OpenCV upstream releases와 [2026 기술위원회 기록](https://github.com/opencv/opencv/wiki/2026): 이번 구간 새 릴리스/회의 기록을 확인하지 못했다. upstream release 목록은 OpenCV 4.14.0(7-19) 및 OpenCV 5.0.0(6-06)을 표시하며, 5.1은 아직 정식 release로 취급하지 않는다.
- Isaac Sim 문서/NGC: 확인된 최신은 6.2.0/6.2.0.1로, 비교 기준일 이전 공개다. Isaac Lab 3.0.0은 별도 항목으로 누락을 정정했다.
- [LeRobot GitHub releases](https://github.com/huggingface/lerobot/releases): 최신 표시는 v0.6.1(8-03)이며 이번 비교 구간 새 numbered release는 없었다. 사용자 프로젝트에 적용할 때 v0.6.1 breaking change와 robot/firmware 호환성은 별도 검증한다.
- Gazebo upstream release와 Hugging Face robotics dataset 검색 결과: 이번 비교 구간에 제품 버전 릴리스 또는 핵심 사전에 추가할 신규 6축 실기 trajectory dataset을 공식 제작자 카드로 검증하지 못했다. 검색된 Hub의 최근 수정일만으로 새 데이터 공개나 라이선스를 단정하지 않았다.

## 남은 확인

- MuJoCo 3.16/3.17 API 변화가 팀 MJCF 모델, custom plugin/decoder, 특정 MuJoCo-ROS 2 bridge와 호환되는지 실제 환경에서 검증.
- Isaac Lab 3.0 backend별 task/ROS bridge matrix, GPU·driver 요구사항, 개별 asset/dependency license를 사용 전에 확인.
- ros2_control #3716/#3718이 maintainer triage·merge·릴리스로 이어지는지, 영향 버전이 명확해지는지 추적.
- LeRobot v0.4.0 날짜 모순은 W44 미해결 항목으로 유지; 이번 주 upstream releases 목록상 latest는 v0.6.1.

## 후속 상태 정정 (2026-11-09)

- #3718 중첩 namespace YAML 문제는 [수정 PR #3719](https://github.com/ros-controls/ros2_control/pull/3719)이 11-02 master에 병합됐고 [Jazzy #3746](https://github.com/ros-controls/ros2_control/pull/3746), [Kilted #3747](https://github.com/ros-controls/ros2_control/pull/3747) backport도 병합됐다. 실제 apt 패키지 반영 버전은 배포판별 changelog에서 확인해야 한다.
- #3716 shutdown race는 [수정 PR #3721](https://github.com/ros-controls/ros2_control/pull/3721)이 11-09 확인 시 여전히 열려 있어 해결로 간주하지 않는다.
- simulator reset/backward clock 대응 [PR #3745](https://github.com/ros-controls/ros2_control/pull/3745)도 열려 있다. 통합별 재초기화·controller 복구 요구사항은 계속 직접 검증한다.
- W45 시점에 확인했던 MuJoCo 3.17.0은 더 이상 최신 버전이 아니다. [MuJoCo 4.0.0](https://github.com/google-deepmind/mujoco/releases/tag/4.0.0)이 11-06 정식 공개됐으므로 최신 상태와 호환성 주의는 [W46 노트](2026-W46.md)를 따른다.
- W45에서 OpenCV 5.1을 아직 release로 취급하지 않았으나 [5.1.0 release](https://github.com/opencv/opencv/releases/tag/5.1.0)가 11-06 공개됐다. LeRobot도 v0.6.1 이후 [v0.7.0](https://github.com/huggingface/lerobot/releases/tag/v0.7.0)이 11-05 공개됐다. 세 항목의 확인 날짜 차이로 인한 정상적인 주간 상태 갱신이다.
