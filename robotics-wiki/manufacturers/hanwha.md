# 한화로보틱스 모델·매뉴얼 안내

- 확인일: 2026-10-21
- 공식 문서 허브: [다운로드 센터](https://hanwharobotics.com/en/newsroom/download?menuSeq=85)

## HCR 매뉴얼 목록

| 세대 | 모델 | 확인된 자료 |
|---|---|---|
| 2세대 | HCR-3A, HCR-5A, HCR-12A | 공식 다운로드 센터의 “HCR 2nd Generation User Manual” 및 2D/3D 도면 |
| 3세대 | HCR-14, HCR-10L | 공식 다운로드 센터의 “HCR 3rd Generation User Manual” |
| 프로그래밍 | HCR 계열 적용 Rodi Script | 공식 다운로드 센터의 Rodi Script Programming Guide |

각 문서 상세 페이지/첨부 파일은 다운로드 허브에서 제목을 선택한다. 동일한 모델 번호가 세대별로 다르면 세대 매뉴얼이 우선이며, 공개 목록에는 모든 HCR 모델의 개별 매뉴얼이 확인되지 않았다. 매뉴얼이 나열되지 않은 모델은 공급사에 정확한 문서 개정판을 요청한다.

## 인수·개발 전 확인

명판의 HCR 모델/세대, 컨트롤러 모델과 firmware, teach pendant/software, 매뉴얼 revision을 기록한다. Rodi Script 문법/API나 I/O가 세대 간 같다고 추정하지 않는다. ROS 2 연동을 채택할 경우 제조사의 현재 SDK/지원 버전과 공식 저장소를 별도로 검증하고 출처 등록부에 추가한다. 본 색인은 HCR 사용자 매뉴얼의 존재를 기록하며 로봇 셀의 안전 설정을 대신하지 않는다.
