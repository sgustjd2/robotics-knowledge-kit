## 매뉴얼 선택

HD현대로보틱스는 설치·운용·정비 문서를 웹으로 제공하는 HRBook과 다운로드 센터를 운영한다. 다운로드 센터의 매뉴얼 분류에는 Robot Maintenance, Controller Hi5a, Hi6, Hi7, Common 등이 있다. 예를 들어 공식 Hi6-N controller 자료는 적용 로봇 모델 목록과 controller maintenance manual을 함께 표기한다.

| 장비군 | 대표 기종 예 | 문서 선택 기준 |
|---|---|---|
| 산업용 로봇 암 | HH 계열, HDR 계열, HDP 계열 | [제품/다운로드 페이지](https://www.hd-hyundairobotics.com/en/biz/product)에서 정확한 robot model·사양·적용 컨트롤러 확인 후 매뉴얼 선택 |
| 컨트롤러 | Hi5a, Hi6, Hi7 및 세부형식 | 다운로드 센터의 controller 별 Manual 분류와 제어기 명판을 일치시킴 |
| 유지보수/공통 | Robot Maintenance, Common | 암·컨트롤러에 해당하는 보조 문서인지 적용 범위를 확인 |

모델별 첨부 문서 및 지원 버전은 센터 검색/필터가 현재 페이지에서 동적으로 제공한다. 이 색인은 특정 조합의 최신 개정판 번호를 고정하지 않는다. 실제 장비의 암 모델, controller 세부 모델, TP, software version이 모두 일치하는 설치·운전·정비 문서를 선택한다.

## 안전 및 통합

정비/수동운전/자동운전 지침을 분리해 읽고, 로봇·제어기 조합에 해당하는 안전 매뉴얼과 셀 위험성 평가를 따른다. HRLadder 등 부가 도구는 적용 controller와 software version이 맞는지 제품 지원 페이지에서 확인한다. 공개 매뉴얼 링크가 있더라도 현장 납품 개정판의 대체 근거로 삼지 않는다.
